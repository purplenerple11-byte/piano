The idea in one minute

The song has two halves.

  • Chords 1–4 sit near home: Cm, then Fm over a C bass, then B♭ and E♭. The left hand holds C for two chords, then steps to B♭ and up to E♭.
  • Chords 5–9 walk the bass down: A♭ → F → D, then the lone C, then G. G7♭9 at the end pulls hard back to Cm, so the loop starts again.

Things that make it easier under the hand:

  • A♭maj7 is C minor with A♭ underneath. Right hand plays C–E♭–G, the same notes as the Cm you opened with.
  • Fm7 → D dim → G7♭9 keep F and A♭ on the bottom. Thumb on F, next finger on A♭, for all three. Only the top changes: C–E♭, then D, then B–D.
  • The B in G7♭9 is the note that wants to climb to C. That's what makes the end of the loop feel like it has to come back round.

How this works

Each hand alone first, as short lines. The right-hand chords are played as broken chords, bottom note up. Press Start and play each note as the cursor reaches it. Right notes go green, wrong ones red. Turn on Hints if a position won't stick. It grades notes, not speed, so go slow. The record sits around ♩=87.

Then the last block puts both hands together, one chord per column. Hold the whole chord down at once.
