Say You Will

Kanye West, from 808s & Heartbreak. Four chords in C minor, going round and round. Learn them and you can play the whole song's harmony.

What this is, honestly There's no MIDI for this one, so this page teaches the chords, not the vocal melody. The key and progression come from published analyses (Hooktheory and Chordify both list C minor): A♭maj7 → Fm → Dm7♭5 → G7, looped. The left-hand roots are exact. The right-hand shapes are my voicings, picked so your hand barely moves. The record's synths voice them their own way.

If you send me a MIDI or sheet music, I can add the melody the same way Never See Me Again has it.

The idea in one minute

The loop is a slow walk down: A♭ → F → D → G in the bass. G7 at the end pulls you back to the start. That pull is what makes the song feel like it never resolves.

Two tricks make it easy under the hand:

  • A♭maj7 is just C minor with A♭ underneath. Left hand plays A♭, right hand plays C–E♭–G. You already know that triad.
  • Fm and Dm7♭5 use the same right hand. C–F–A♭ stays put. Only the left hand moves, F down to D. Same three notes on top, darker sound, because the bass changed.

For G7, move two fingers: C goes up to D, A♭ goes up to B. F stays. That B is the note that wants to climb back to C, which pulls you round to the top.

How this works

First each hand alone, as short lines. Press Start and play each note as the cursor reaches it. Right notes go green, wrong ones red. Turn on Hints if a position won't stick. The drill grades notes, not speed, so go slow. The record sits around ♩=87, which is already relaxed.

Then the last block puts both hands together, one chord per column, twice through the loop.
